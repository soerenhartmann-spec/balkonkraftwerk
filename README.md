# ☀️ Balkonkraftwerk Tracker

Persönlicher Tracker für Balkonkraftwerk-Daten mit Supabase als Datenbank.

## Stack
- React 18 + Vite
- Recharts (Diagramme)
- Supabase (Datenbank)
- Vercel (Hosting)

## Lokale Entwicklung

```bash
npm install
npm run dev
```

## Deploy

Automatisch via Vercel bei jedem Push auf `main`.

## Supabase Setup

SQL für Tabelle liegt in `supabase_setup.sql`.
